## Méthode du contrôle synthétique
### Articles de référence

- [Abadie et al. (2010)](https://economics.mit.edu/sites/default/files/publications/Synthetic%20Control%20Methods.pdf).

### Packages Python créées par d'autres dévelopeurs
Il existe plusieurs packages en R ou Python créés par d'autres développeurs pour implémenter la méthode du contrôle synthétique. Parmi eux, on peut citer :
- `synthdid` : un package R pour l'estimation des effets causaux en utilisant la méthode du contrôle synthétique. Le lien vers le dépôt GitHub est [ici](https://github.com/synth-inference/synthdid). La documentation est par [là](https://synth-inference.github.io/synthdid/).
- `pySynth` : une autre implémentation de la méthode du contrôle synthétique, en Python cette fois-ci. Le lien vers le dépôt GitHub est [ici](https://github.com/MasaAsami/pysynthdid).
- `SyntheticControlMethods` : une dernière implémentation de la méthode du contrôle synthétique en Python, par Oscar Engelbrektson, sous licence MIT. Le lien vers le dépôt PyPI est [ici](https://github.com/OscarEngelbrektson/SyntheticControlMethods) et la page est [là](https://pypi.org/project/SyntheticControlMethods/).
