### Note sur le projet TICELEC

&nbsp;&nbsp;&nbsp;La section 3 expose sommairement le protocole d'évaluation du projet de recherche TICELEC (les Technologies de l'Information pour une Consommation ELECtrique responsable). Le projet est une évaluation de terrain conduite sur la période 2011-2012 ; le lecteur intéressé pourra consulter le [rapport final](ticelec_rapportfinal_2013_02.pdf).[^1] Ce projet a donné lieue à une série de publications,[^2] et d'entretiens dans des journeaux ; voir le site de [Nathalie Lazaric](https://www.nathalie-lazaric.fr/2011-2013-ticelec-technologies-de-linformation-pour-une-consommation-electrique-responsable/), coordinatrice du projet. 

[^1]: Alegret, S., Aufeuvre, M., Bourgeois, A., Brie, O., Kendel, A., Lazaric, N., Pinson, M., Salies, E. (2013). Les Technologies de l'Information pour une Consommation ELECtrique responsable. Rapport final de recherche. &Eacute;tude réalisée dans le cadre du programme "Agir ensemble pour l'énergie" pour le compte de la région PACA. Financé par la région (fincancement No 1140C0397), le conseil général et l'ADEME (financement No 19364-22937), 153 p.

[^2]: Voir par exemple [Kendell et al. (2017)](https://doi.org/10.1016/j.enpol.2017.06.020).
